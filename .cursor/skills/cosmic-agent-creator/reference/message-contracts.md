# Message Contracts — shared/contracts.py

All models live in `shared/contracts.py`. Every agent imports from here. Never duplicate these definitions.

## TaskEnvelope (Bidirectional)

The standard message format for ALL orchestrator-agent communication.

```python
from pydantic import BaseModel, Field, field_validator
from datetime import datetime
from typing import Literal

class TaskEnvelope(BaseModel):
    task_id: str                                    # 'tsk_abc123'
    task_list_id: str                               # Groups related tasks
    parent_task_id: str | None                      # For subtask trees
    session_id: str | None                          # Links task to session context
    sender: str                                     # 'cosmic/orchestrator:1.0.0'
    recipient: str                                  # 'cosmic/research-agent:1.0.0'
    intent: str                                     # 'research.topic'
    input: dict                                     # Intent-specific payload
    input_artifacts: list[ArtifactManifest] = []    # Files passed TO the agent
    idempotency_key: str                            # UUID — required, enforced via SETNX
    deadline_ts: datetime | None                    # Timezone-aware or naive UTC
    priority: Literal['high', 'normal', 'low'] = 'normal'
    leader_epoch: int | None = None                 # Fencing token set by orchestrator
    signature: str                                  # HMAC-SHA256 of canonical payload
    contract_version: str = CURRENT_WRITE_VERSION   # dynamic — see contract versioning
    created_at: datetime = Field(default_factory=utcnow)
    source: Literal['user', 'cron', 'webhook', 'heartbeat', 'hook', 'agent'] = 'user'
    source_id: str | None = None                    # Origin identifier
    channel: str | None = None                      # Platform: 'desktop', 'whatsapp:+1234', etc.

    @field_validator('contract_version')
    @classmethod
    def check_contract_version(cls, v: str) -> str:
        if v not in ACCEPTED_READ_VERSIONS:
            raise ValueError(
                f'Unacceptable contract version: {v}. '
                f'Accepted: {ACCEPTED_READ_VERSIONS}'
            )
        return v
```

### Field Details

| Field | Type | Notes |
|---|---|---|
| `task_id` | str | Unique. Format: `tsk_<random>`. Generated by orchestrator. |
| `task_list_id` | str | Groups related tasks in a session. |
| `parent_task_id` | str\|None | Links child to parent in subtask trees. |
| `session_id` | str\|None | Links task to session. Agents use this for their own `store/data/` queries. |
| `sender` | str | Full agent_id of sender. Orchestrator uses this to look up HMAC secret. |
| `recipient` | str | Full agent_id of recipient. Used for stream routing. |
| `intent` | str | `<domain>.<action>` format. Maps to agent's intent handler. |
| `input` | dict | Intent-specific payload. May contain `auth` key (credential passthrough). |
| `input_artifacts` | list | Typed file references — verified by SHA256 before read. |
| `idempotency_key` | str | UUID. SETNX guard before every execution. |
| `deadline_ts` | datetime\|None | Absolute deadline. Agent should check `deadline_remaining_sec()`. |
| `priority` | Literal | `high`, `normal`, or `low`. Determines which stream tier. |
| `leader_epoch` | int\|None | Fencing token. Agent rejects tasks from stale epochs. |
| `signature` | str | HMAC-SHA256. Stripped before passing to agent logic. |
| `contract_version` | str | From `CURRENT_WRITE_VERSION` config. Validated on read. |
| `source` | Literal | Origin type. Propagated to child tasks. |
| `source_id` | str\|None | Specific origin instance. Propagated to child tasks. |
| `channel` | str\|None | Platform/interface. Format: `{platform}` or `{platform}:{id}`. Null for internal events. |

For reverse tasks created by agents:
- `source='agent'`
- `source_id=<sender agent_id>`
- `channel=<parent task channel>` when the suspended task came from a user-facing channel

### input.auth Convention

When an intent has `auth_requirements` in `agent_card.yaml`, the orchestrator resolves credentials
and places them in `input.auth` before dispatch:

```python
# Example: input dict for a docs.edit task
{
    'query': 'Add a conclusion section to the project proposal',
    'doc_id': 'abc123',
    'auth': {
        'credential_ref': 'cred_9f3a...',       # opaque reference for audit
        'access_token': 'ya29.a0AfH6SM...',      # short-lived (5-15 min)
        'provider': 'google',
        'scopes': ['https://www.googleapis.com/auth/documents'],
        'expires_at': '2025-01-15T10:05:00+00:00',
    },
}
```

**Hard rules:**
- NEVER included in EventEnvelopes, artifacts, logs, store/, runtime/, or learnings.md
- The base class extracts `input.auth` before execute() and exposes it via `self.auth`
- `self.auth` is runtime-only — never serialized
- `input.auth` IS covered by the HMAC signature (part of `input: dict`)
- If `input.auth` is absent, do NOT attempt provider API calls
- If access token expires mid-task, suspend and request refresh via `orchestrator.refresh_credential`

## EventEnvelope (Agent -> Orchestrator)

How agents report progress. Emitted asynchronously as work proceeds.

```python
class EventEnvelope(BaseModel):
    task_id: str
    agent_id: str                   # who emitted this
    event_type: Literal[
        'task.accepted',            # agent received and validated task
        'task.progress',            # intermediate progress update
        'task.suspended',           # agent waiting for reverse-task reply
        'task.resumed',             # agent continuing after suspension
        'task.deferred',            # NON-TERMINAL: another instance executing
        'artifact.added',           # artifact produced, manifest in payload
        'task.completed',           # TERMINAL: success
        'task.failed',              # TERMINAL: failure
        'task.dlq',                 # TERMINAL: dead letter queue
        'task.rejected',            # NON-TERMINAL: stale epoch — triggers redrive
    ]
    seq: int                        # monotonic PER-TASK via redis.incr()
    payload: dict                   # event-type-specific data
    emitted_at: datetime
    contract_version: str = CURRENT_WRITE_VERSION

    @field_validator('contract_version')
    @classmethod
    def check_contract_version(cls, v: str) -> str:
        if v not in ACCEPTED_READ_VERSIONS:
            raise ValueError(
                f'Unacceptable contract version: {v}. '
                f'Accepted: {ACCEPTED_READ_VERSIONS}'
            )
        return v
```

### Event Types

| Event | Terminal? | When | Agent Action |
|---|---|---|---|
| `task.accepted` | No | After HMAC verify + epoch check passes | Emit immediately |
| `task.progress` | No | During execution (step updates, partial results) | Emit as needed |
| `task.suspended` | No | Agent needs reverse-task reply | Serialize state, wait |
| `task.resumed` | No | Agent received reply, continuing | Resume execution |
| `task.deferred` | No | Another instance already executing (idempotency) | XACK, let orchestrator handle |
| `artifact.added` | No | File produced during execution | Include ArtifactManifest in payload |
| `task.completed` | **Yes** | Success | Return AgentResult |
| `task.failed` | **Yes** | Failure | Return AgentResult with error |
| `task.dlq` | **Yes** | Dead letter queue | Orchestrator moves task |
| `task.rejected` | No | Stale epoch detected | Orchestrator will redrive |

**seq is per-task, not per-agent.** Resets to 1 for every new task_id. Allocated via `redis.incr(f'event_seq:{task_id}')`.

## AgentResult

```python
class AgentResult(BaseModel):
    status: Literal['completed', 'failed']
    output: dict                    # Intent-specific result data
    artifacts: list[ArtifactManifest]
    error: AgentError | None        # Only present when status='failed'
```

## AgentError

```python
class AgentError(BaseModel):
    code: str               # 'TIMEOUT', 'NETWORK_ERROR', 'RATE_LIMITED', 'INVALID_INPUT', etc.
    retryable: bool         # True → orchestrator may retry. False → terminal.
    message: str            # Human-readable error description
    next_action: str | None # 'retry', 'escalate', 'skip'
```

### Error Code Classification

| Code | Retryable | next_action | When |
|---|---|---|---|
| `TIMEOUT` | True | `retry` | External API or task exceeded deadline |
| `NETWORK_ERROR` | True | `retry` | Connection failure, DNS resolution, etc. |
| `RATE_LIMITED` | True | `retry` | External API rate limit hit |
| `INVALID_INPUT` | False | `escalate` | Bad input from orchestrator |
| `AUTH_ERROR` | False | `escalate` | Credential invalid/revoked/insufficient scopes |
| `SCHEMA_VIOLATION` | False | `escalate` | Output doesn't match schema |
| `PLAN_INCOMPLETE` | False | `escalate` | Agent returned completed with pending StepPlan steps |
| `DEADLINE_EXCEEDED` | False | `skip` | Absolute deadline passed |
| `INTERNAL_ERROR` | False | `escalate` | Unexpected error in agent logic (catch-all) |

## ArtifactManifest

```python
class ArtifactManifest(BaseModel):
    artifact_id: str        # 'art_xyz789'
    task_id: str
    mime: str               # 'application/pdf', 'image/png'
    sha256: str             # integrity hash — MANDATORY
    path: str               # 'runs/artifacts/tsk_abc123/paper.pdf'
    source_url: str | None  # where the content came from (if applicable)
    created_by_agent: str   # agent_id
    created_at: datetime
```

**Path rules:** All artifact paths are validated against an allowlist before any file read. Path traversal attacks are blocked. Allowed roots: `runs/artifacts/`, `agents/*/store/`, `agents/*/runtime/`.
