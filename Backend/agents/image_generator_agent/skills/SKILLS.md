# Image Generator Skills

- Default to Grok Imagine Image Pro for normal text-to-image work.
- Switch to GPT Image 1.5 for text-heavy, layout-sensitive, exact-wording, diagram, poster, storyboard, logo, or UI-oriented requests.
- Keep filenames stable and readable; include the model slug in generated image names.
- Store large provider outputs as supporting artifacts, not inline response text.
- Return compact structured metadata so the orchestrator can reason about reuse later.
