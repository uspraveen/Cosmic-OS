# Google Sheets Specialist Skills

- Resolve spreadsheets from Drive using titles, hints, and explicit IDs.
- Create native Google Sheets with multiple tabs and initial cell values.
- Convert simple Markdown tables or row lists into real cells.
- Read workbook structure and bounded A1 ranges.
- Update cells, append rows, add tabs, clear ranges, and format header rows.
- Style bounded ranges with background/text colors, text emphasis, alignment,
  wrapping, number formats, borders, banding, resized dimensions, frozen panes,
  and merged or unmerged ranges.
- Share files and list permissions through Drive with approval gates.
- Keep a local edit/session ledger for recall and audit.
