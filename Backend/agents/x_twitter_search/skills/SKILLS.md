# X Search Skills

- Use handle filters when the orchestrator clearly wants a search restricted to one or more known accounts.
- Use date filters when the user asks for recent windows, launch-day reactions, or post-event analysis.
- Prefer notable-post excerpts that are short, attributable, and directly relevant to the answer.
- Treat citations as the grounding layer; return them cleanly.
- Keep the final briefing compact and high-signal.
